# まなたま — こたえて そだてる なかまたち

小学1〜6年生むけの学習ゲームです。問題に答えると「ごはん」がもらえて、たまごから仲間が生まれ、育つと問題のモンスターと戦ってくれます。
中1向けの `aoto2`(たまごクエスト)をもとに、小学生用に作り直しました。`aoto2` は変更していません。

## 使い方

- **PC**: `start.cmd` をダブルクリック(または `index.html` を開く)。インストール・ログイン不要。
- **スマホ**: フォルダごと GitHub Pages / Netlify / Vercel などに置けば、そのまま動きます。記録は端末のブラウザ(localStorage)に保存されます。

はじめて開くと、たまごに名前をつけて、学年(1〜6年)を選びます。

## 毎日 ひらきたくなる しくみ(遊びながら 自然に 勉強)

```
毎日ひらく → ログインボーナスで 🎟️ガチャチケット
   → 🎰ガチャで オリジナルの「ガチャなかま」が出る(★〜★★★★)
   → なかまを そだてるには 🍙ごはん が いる
   → ごはんは もんだいを とくと もらえる ← ここで 勉強
   → 「きょうの ミッション」を ぜんぶ クリアすると もう1まい 🎟️
```

- **ログインボーナス**: 7日で1しゅうの スタンプカード(7日めは チケット3まい)。毎日つづけなくても 進むので、休んでも 損しない。
- **ガチャ**: ガチャなかま 14しゅるい(ノーマル55%・レア30%・スーパーレア12%・ウルトラレア3%)。10回に1回は ★★★以上が かならず出る。まだ もっていない子が 出やすい。おなじ子が出たら その子に ごはん+3。
- **ガチャなかまを そだてる**: ごはんで ベビー → こども → おとな(おとなに なると キラキラや オーラ)。「いっしょに たたかう」で、問題の バトルに パートナーとして 出てくれる。
- **きょうの ミッション**: もんだいを3もん正解 / なかまに ごはんを3かい / ふくしゅうで1もん正解(ふくしゅうが ないときは 6もん正解)。それぞれ ごはん、ぜんぶで チケット。
- **ふくしゅう**: まちがえた問題・「わからない」を押した問題が 自動で たまる。自分で正解できたら「おぼえた!」で リストから消える。

## 大切にしていること

**「何年生だから、これくらいできるはず」とは考えない。** 勉強が得意な子も、苦手な子も、生まれつき読み書きがむずかしい子も、同じように遊べることを目指しています。

- **読み上げは全学年・全画面**: 問題文・選択肢・ヒント・解説・「わからない」の説明まで、すべて読み上げます。問題が出たら自動で読む/ボタンで読む を選べます。選択肢の横の 🔊 で、ひとつずつ聞けます。
- **学年と「やさしさ」は別**: 学年は「どの単元の問題が出るか」だけを決めます。次の設定は学年に関係なく、ホームの「👀 みやすさ」でその子に合わせて変えられます。
  - じの かきかた: かんじ＋ふりがな / ひらがなだけ / かんじだけ
  - じの おおきさ: ふつう / おおきい / とても おおきい
  - こたえの かず: 2つ / 3つ / 4つ
  - こえの はやさ: ゆっくり / ふつう / はやめ
- **さかのぼりは学年をまたぐ**: 「😵 わからない」を押すと、やさしい説明 → 確かめ → まだむずかしければ「もっとやさしく」で前の内容へ戻れます。たとえば5年の分数のたし算から、2年の九九のしくみまで、ボタンだけでたどれます。
- **戻っても「下の学年」とは見せない**: 子どもの画面には「何年生の内容か」は出しません。どこまで戻ったかは「おとなのへや」(ホーム下の「おとなの人へ」を長押し)で大人だけが確認できます。
- **罰なし**: まちがえても「わからない」を押しても減点なし。前提を確かめて正解すると、ごはんがもらえます。

## 教材(いまの範囲)

小学1〜6年 × 6教科(国語・算数・生活・理科・社会・英語)の **208単元すべて** に問題と説明があります(スキル208・問題 約1700問)。

| 教科 | 学年 |
| --- | --- |
| 国語 | 1〜6年(ひらがな・かたかな・漢字の読み・文法・物語/説明文の読み取り・敬語・俳句/短歌・古典 など) |
| 算数 | 1〜6年(計算は自動生成。図形・グラフ・量・割合・比・データ など) |
| 生活 | 1・2年 |
| 理科 | 3〜6年 |
| 社会 | 3〜6年 |
| 英語 | 3〜6年(英語の部分は英語の声で読み上げ) |

単元表は文部科学省「小学校学習指導要領(平成29年告示)」をもとにしています。単元の順番は教科書ごとにちがうので、一般的な並びです。
国語2年の文章は、1・2年で習う漢字だけを使っています(学年別漢字配当表)。

### 「わからない」の説明

「😵 わからない」を押すと、単元のやさしい説明(意味 → 例 → 手順)のあと、**その問題のヒント**と、**答えまでのとき方(こたえまで いっしょに)**が必ず出ます。そのあと確かめの問題に答えて、元の問題にもどります。まだむずかしければ「もっとやさしく」で前の内容へさかのぼれます。

### 問題のチェック(`tools/check.js`)

- 答えが選択肢にあるか、選択肢がかぶっていないか
- 計算問題の答えが正しいか(実際に計算して確かめる)
- **見ただけで答えがわかってしまわないか**(答えだけカタカナ・答えだけ漢字・答えだけ長い、などを一覧にする)
- 説明・確かめ・前提がそろっているか

## ファイル

- `index.html` / `css/style.css`
- `js/util.js` 保存・効果音・読み上げ・ふりがな表示
- `js/settings.js` 学年えらび・みやすさ設定
- `js/game.js` 本体(ホーム・バトル・クイズ・ずかん・おとなのへや)
- `js/gacha.js` ログインボーナス・ガチャ・ガチャなかま・きょうのミッション・ふくしゅう
- `js/tutor.js` 「わからない」→ 説明 → 確かめ → 前提へ戻る
- `js/visuals.js` 説明の図(数の道・分数の帯・とけい など)
- `js/write.js` / `js/writing.js` 手書きで答える・漢字/英単語の書く練習(漢字は学年ごと)
- `js/creatures.js` / `js/enemies.js` 仲間とモンスター(SVG)
- `js/data.js` 教材データ(自動生成。直接編集しない)
- `src/` 教材の元ファイル(`curriculum.js` 単元表 / `sansu*.js` 算数 / `kokugo*.js` 国語 / `seikatsu_rika.js` 生活・理科 / `shakai.js` 社会 / `eigo.js` 英語 / `lib.js` 書き方)
- `tools/build.js` 教材ビルド / `tools/check.js` 問題チェック / `tools/align.js` 説明と問題の対応チェック / `tools/dump.js` 問題の一覧表示

## 教材の足し方

1. `src/` の教材ファイルに `M.skill({...})` を足す(書き方は `src/lib.js` の先頭)。漢字はふつうに書けば、ふりがなは自動で付きます。
   - 読みを指定したいとき: `{何|なん}`
   - ふりがなを付けたくないとき(漢字の読みを聞く問題など): `«学校»`(読み上げでは「この字」と読みます)
2. ビルドする:
   ```
   cd tools
   npm install
   node build.js
   ```
   `js/data.js` が作り直されます。続けて `node check.js` で問題をチェックします。ふりがなは形態素解析(kuromoji)で付けるので、まれに読みがちがうことがあります。`tools/readings.txt` に使った読みの一覧が出るので確認してください。
