# まなたま — こたえて そだてる なかまたち

小学1〜6年生むけの学習ゲームです。問題に答えると「ごはん」がもらえて、たまごから仲間が生まれ、育つと問題のモンスターと戦ってくれます。
中1向けの `aoto2`(たまごクエスト)をもとに、小学生用に作り直しました。`aoto2` は変更していません。

## 使い方

- **PC**: `start.cmd` をダブルクリック(または `index.html` を開く)。インストール・ログイン不要。
- **スマホ**: フォルダごと GitHub Pages / Netlify / Vercel などに置けば、そのまま動きます。記録は端末のブラウザ(localStorage)に保存されます。

はじめて開くと、たまごに名前をつけて、学年(1〜6年)を選びます。

## 大切にしていること

**「何年生だから、これくらいできるはず」とは考えない。** 勉強が得意な子も、苦手な子も、生まれつき読み書きがむずかしい子も、同じように遊べることを目指しています。

- **読み上げは全学年・全画面**: 問題文・選択肢・ヒント・解説・「わからない」の説明まで、すべて読み上げます。問題が出たら自動で読む/ボタンで読む を選べます。選択肢の横の 🔊 で、ひとつずつ聞けます。
- **学年と「やさしさ」は別**: 学年は「どの単元の問題が出るか」だけを決めます。次の設定は学年に関係なく、ホームの「👀 みやすさ」でその子に合わせて変えられます。
  - じの かきかた: かんじ＋ふりがな / ひらがなだけ / かんじだけ
  - じの おおきさ: ふつう / おおきい / とても おおきい
  - こたえの かず: 2つ / 3つ / 4つ
  - こえの はやさ: ゆっくり / ふつう / はやめ
- **さかのぼりは学年をまたぐ**: 「😵 わからない」を押すと、やさしい説明 → 確かめ → まだむずかしければ「もっとやさしく」で前の内容へ戻れます。たとえば5年の分数のたし算から、2年の九九のしくみまで、ボタンだけでたどれます。
- **戻っても「下の学年」とは見せない**: 子どもの画面には「何年生の内容か」は出しません。どこまで戻ったかは「おとなのへや」(ホーム下の「おとなの人へ」を長押し)で大人だけが確認できます。
- **罰なし**: まちがえても「わからない」を押しても減点なし。前提を確かめて正解すると、ごはんがもらえます。

## 教材(いまの範囲)

| 教科 | 問題がある学年 |
| --- | --- |
| 算数 | 1〜6年(各学年 5〜9単元、問題は自動生成で計 600問以上) |
| 国語 | 1・2年(ひらがな・かたかな・漢字の読み・主語と述語・なかまのことば・反対のことば・ようすのことば・お話の読み取り・せつめい文のじゅんじょ) |
| 生活・理科・社会・英語 | 単元表のみ(「じゅんびちゅう」) |

単元表(1〜6年 × 6教科、208単元)は文部科学省「小学校学習指導要領(平成29年告示)」をもとにしています。単元の順番は教科書ごとにちがうので、一般的な並びです。

国語2年の文章は、1・2年で習う漢字だけを使っています(学年別漢字配当表)。

## ファイル

- `index.html` / `css/style.css`
- `js/util.js` 保存・効果音・読み上げ・ふりがな表示
- `js/settings.js` 学年えらび・みやすさ設定
- `js/game.js` 本体(ホーム・バトル・クイズ・ずかん・おとなのへや)
- `js/tutor.js` 「わからない」→ 説明 → 確かめ → 前提へ戻る
- `js/visuals.js` 説明の図(数の道・分数の帯・とけい など)
- `js/write.js` / `js/writing.js` 手書きで答える・漢字/英単語の書く練習(漢字は学年ごと)
- `js/creatures.js` / `js/enemies.js` 仲間とモンスター(SVG)
- `js/data.js` 教材データ(自動生成。直接編集しない)
- `src/` 教材の元ファイル(`curriculum.js` 単元表 / `sansu12.js` `sansu36.js` 算数 / `kokugo12.js` 国語 / `lib.js` 書き方)
- `tools/build.js` 教材ビルド

## 教材の足し方

1. `src/` の教材ファイルに `M.skill({...})` を足す(書き方は `src/lib.js` の先頭)。漢字はふつうに書けば、ふりがなは自動で付きます。
   - 読みを指定したいとき: `{何|なん}`
   - ふりがなを付けたくないとき(漢字の読みを聞く問題など): `«学校»`(読み上げでは「この字」と読みます)
2. ビルドする:
   ```
   cd tools
   npm install
   node build.js
   ```
   `js/data.js` が作り直されます。ふりがなは形態素解析(kuromoji)で付けるので、まれに読みがちがうことがあります。`tools/readings.txt` に使った読みの一覧が出るので確認してください。
