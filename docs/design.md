# まなたま 設計メモ (2026-11-14)

目的: 小学1〜6年生が毎日開きたくなり、勉強が得意な子も苦手な子も、自分のペースで理解できること。

## 方針
- 遊びの部分(たまご・ごはん・バトル・ずかん)は aoto2 のまま。小2の子が夢中になったのはここ。
- 学年は「出る単元」だけを決める。読みやすさ(ふりがな・ひらがなだけ・文字の大きさ・選択肢の数・読み上げ速度)は学年と切り離して、ひとりずつ設定する。
- 読み上げは全学年・全画面。問題文は自動で読む(切りかえ可)。選択肢・ヒント・解説も 🔊 で聞ける。
- 「わからない」で、前提の説明へ学年をまたいでさかのぼる。子どもの画面に学年は出さない(おとなのへやでだけ見える)。
- 罰なし。前提の確認に正解するとごはん。

## データ
- 教材は src/ に書き、tools/build.js が kuromoji でふりがな({漢字|かな})と文節の区切り(¦)を付けて js/data.js にする。
- 表示モード: ruby / kana(ひらがなだけ。区切りを空白に) / kanji。
- 算数は問題を生成(シード固定)。国語は手書きの問題。
- 前提(prereq)は概念どうしをつなぎ、学年をまたぐ(例: 5年 通分 → 倍数 → 2年 九九)。

## 制約
- 声は端末の音声に依存。
- 記録は端末内のみ(ひきつぎコードで移せる)。
